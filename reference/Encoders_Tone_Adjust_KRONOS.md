# KRONOS — What the 8 encoders do in Tone Adjust mode, by engine

## How it works

In Program mode, when the **TONE ADJ/EQ** button is set to **TONE ADJ** (TONE ADJ LED lit), the 8 encoders (rotary knobs) on the Control Surface no longer control the mixer. They act directly on parameters of the program instead.

Each synthesis engine has its own **default assignment**, listed below for each engine.

- **Source:** KRONOS Parameter Guide, "Tone Adjust Default Settings" figures.
- **Parameter names:** given exactly as they appear on the KRONOS.
- **Edited programs:** a program can reassign its encoders. This document only covers the default assignments.

---

## HD-1 — PCM (sample-based) synthesis

| Encoder | Parameter | What it does |
|---|---|---|
| 1 | Pitch Stretch | Shifts the samples relative to the note played, which changes the timbre |
| 2 | Pitch LFO1 Intensity | Depth of the vibrato produced by LFO 1 |
| 3 | OSC1 Filter LFO1 Int. to A | Modulation of filter A by LFO 1 (cyclic "wah" effect) |
| 4 | OSC1 Amp LFO1 Intensity | Modulation of the volume by LFO 1 (tremolo) |
| 5 | LFO1 Speed | Speed of LFO 1 |
| 6 | OSC1 LFO1 Waveform | Waveform of LFO 1 |
| 7 | Amp Velocity Intensity | How much the volume responds to playing strength (velocity) |
| 8 | OSC1 Drive | Saturation (Drive) of oscillator 1 |

## AL-1 — Virtual analogue synth

| Encoder | Parameter | What it does |
|---|---|---|
| 1 | OSC1 Width/Phase / Detune AMS Int. | Waveshape of oscillator 1 (width or phase) or detune, depending on the selected waveform |
| 2 | OSC2 Width/Phase / Detune AMS Int. | Same for oscillator 2 |
| 3 | Filter A EG Intensity | How much the envelope affects filter A |
| 4 | Filter B EG Intensity | How much the envelope affects filter B |
| 5 | FM Amount | Amount of frequency modulation between oscillators |
| 6 | Drive | Saturation |
| 7 | LFO1 Speed | Speed of LFO 1 |
| 8 | LFO2 Speed | Speed of LFO 2 |

## CX-3 — Tonewheel organ

| Encoder | Parameter | What it does |
|---|---|---|

| 3 | Expression | Expression pedal (volume) |
| 4 | Overtone Level | Level of the added harmonics |
| 5 | Key-On Click Level | Level of the key click when a key is pressed |
| 6 | EQ Bass | EQ: bass |
| 7 | EQ Mid | EQ: mid |
| 8 | EQ Treble | EQ: treble |

## STR-1 — Physically modelled plucked strings

| Encoder | Parameter | What it does |
|---|---|---|
| 1 | Damping | Damping of the string's high frequencies |
| 2 | Dispersion | String stiffness: makes the harmonics more or less "in tune" |
| 3 | Decay | How long the string rings |
| 4 | Nonlinearity | Nonlinearity of the string (more or less "metallic" or buzzing character) |
| 5 | Excitation Position | Where the string is struck or plucked |
| 6 | Harmonic Position | Position of the harmonic point on the string |
| 7 | Pickup 1 Position | Position of pickup 1 along the string |
| 8 | Pickup 2 Position | Position of pickup 2 along the string |

## SGX-2 — Sampled acoustic pianos

| Encoder | Parameter | What it does |
|---|---|---|
| 1 | Lid Position | Lid opening: brighter or duller sound |
| 2 | Resonance Level | Level of string resonance |
| 3 | Amp Velocity Intensity | How much the volume responds to velocity |
| 4 | Release Time | Release time of the notes |
| 5 | Note Release Level | Level of the note-release noise |
| 6 | Mechanical Noise Level | Level of the mechanical noises |

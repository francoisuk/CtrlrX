# /panels — Ctrlr panels

*Modernisé le 4 nov. 2026.*

This folder holds Ctrlr panel projects. A panel is a `.panel` file (XML)
plus the Lua, static data and sources it was generated from.

## Contents

```

├── KronosKontrol\               THIS project (panel 1.0i)
│   ├── docs\                     PROJECT_LAYOUT.md, CTRLR_IDIOMS.md, EDITOR_PLAN.md,

```

## TR-Rack (removed 4 nov. 2026)

`panels/TR-Rack-Editor-main/` was the canonical Ctrlr example; it has no
use anymore and was moved to `_TO_DELETE_2026-11-04/` (corpus root).
What mattered was extracted on 16 oct. 2026 and lives on in
`KronosKontrol/docs/ETUDE_TR-Rack.md` (raw extraction) and
`KronosKontrol/docs/CTRLR_IDIOMS.md` (verified idioms) — read those
before writing any Ctrlr Lua code.

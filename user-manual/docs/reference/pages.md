# Editor page directory (215 numbered pages + FX EDIT template)

Complete list of the EDIT-view pages, grouped by object. Page titles and areas
are exactly as shown in the panel's navigation bar. `Idx` is the page number
within its object set; the panel's PAGE/AREAS/INDEX bar jumps to these pages.

The panel shows **216 page views in total**: 215 numbered pages plus the FX
EDIT template (see the notes at the end of this directory).

## Notes

- Pages with an instance selector (OSC, TIMBRE, NOTE, EXi slot) reuse the same
  page for each instance; the INDEX part of the navigation bar chooses it.
- Program engine pages (areas `ENGINE · …`) are only applicable when the
  current program uses that engine in the selected EXi slot — see
  [Pages and parameters model](../explanation/pages-and-parameters.md).
- The FX EDIT template page is reached from the EFFECTS pages via the FX nav
  entries (IFX1–IFX12, MFX1–MFX2, TFX1–TFX2); it offers 198 effect types. It is
  not numbered like the pages above; with the 215 numbered pages, it makes the
  216 page views in total.

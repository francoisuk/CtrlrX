There will be an OASYS and NAUTILUS version of the KRONOS KONTROL panel and editor.
The Oasys will be called Oasys Omni. The Nautilus version will be called Nautilus Navigator.

The Oasys Omni will use the UI from the graphic file OASYS_B_graphite_touchview_fond.png within the folder \graphics\OASYS of the root ctrlr-project.
For the Nautilus, the reference graphic file is is NAUTILUS_A_noir_abyssal_fond.png inside the folder \graphics\NAUTILUS.
